# 应用服务故障诊断

- 先列出已知事实，再说明可能原因；不要把时间上的相关性说成确定根因。
- 比对异常开始时间与最近发布、配置变更和错误率变化。
- 给出下一步要查的日志或指标，以及各结果会如何改变判断。
- 只能建议评估回滚；实际回滚必须由有权限的人确认。
- 没有工具查询结果时，不得声称已经查到线上状态。
