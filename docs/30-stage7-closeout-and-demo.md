## 五分钟演示顺序

1. 检查 Docker 服务与 `http://localhost:8081/health`，打开 `http://localhost:8081/console/`。
2. 输入仓库首页的 `payment-service` 示例。若时间未自动建议，填 `2026-09-01 10:05`（北京时间）。展示 Evidence ID、三个工具状态、Runbook 来源、主辅 Agent，以及“确认事实”和“待验证假设”的区别。
3. 输入 `10:05 开始 5xx 激增，请帮我排查`。预期先追问受影响服务，不进行全库扫描；在同页补充 `payment-service` 后检查结果是否出现，而非刷新页面。
4. 仅在可信私有演示环境中输入**历史访问令牌**，打开成功记录的详情与 Trace。不要在录屏、幻灯片、终端输出或仓库中展示令牌。
5. 从记录选择“解读已有记录”，问 `哪些是已确认事实、哪些是假设？v2.3.7 一定是根因吗？`。它不应重新查询现场或创建新诊断。只有需要查询新证据时才选“重新诊断”；这是新的一次运行，不继承旧结论。
